# First Log Entry

The portfolio is a product. It has vision, decisions, and a roadmap — exactly like any project I ship.

## What's standing

- Astro 7, static-first, zero-JS by default
- Tailwind v4 with CSS-first tokens (`@theme`)
- Motion (ex-Framer Motion) islands
- i18n native ES/EN
- Content Collections with Zod schemas

## What's coming

- Go + Gin API (Swagger 2.0) with Postgres, sqlc, golang-migrate
- Real case studies following the expedition template
- Contact form wired to the API
