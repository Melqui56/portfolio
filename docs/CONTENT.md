# Content Strategy

Status: **draft**. Refined alongside the profile definition.

## General narrative

> I take products from idea to ship, with technical rigor, design judgment, and a management mindset.

## Site storytelling (draft)

1. **Hero**: one-sentence pitch + three pillars (Engineering / Craft / Management).
2. **Manifesto**: how I think when building (decision > framework, process > outcome).
3. **Featured projects**: 3–4 case studies with the structure:
   `Context → Problem → Decisions → Architecture → Iterations → Results → Lessons`.
4. **Continuous learning**: postgraduates as evidence of strategic direction.
5. **Career roadmap**: where I'm heading (Master's in Project Management).
6. **Contact**: clear and visible.

## Language

## Tone

- Professional, direct, no fluff.
- Show trade-offs and failures: technical honesty.

## Per-project checklist (case study)

- [ ] Problem context
- [ ] Key decisions and why
- [ ] Architecture diagram
- [ ] Iterations / what didn't work
- [ ] Results with metrics
- [ ] Lessons
- [ ] Live demo + repo + study-style README
