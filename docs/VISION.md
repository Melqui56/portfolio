# Portfolio Vision

## Purpose

Showcase my value as a **holistic software engineer**: not only finished projects, but the decision-making process, the architecture, and the judgment behind each one.

## Audience

1. **Recruiters / hiring managers** in tech and video games.
2. **Teams / studios** looking for a profile that combines solid engineering, product vision, and management understanding.
3. **Community** (devs, gamedevs, designers) as a reference for process.

## Value proposition

> A software engineer who takes products from idea to ship — with technical rigor, design judgment, and a management mindset.

## Profile pillars

- **Engineering**: architecture, decisions (ADRs), tests, performance, systems.
- **Craft / Gamedev / Design**: iteration, game feel, UX, fast prototyping.
- **Management (in training)**: roadmap, prioritization, communication, post-mortems.

## Guiding principles

1. **Process over outcome**: every project is told as a case study (context → problem → decisions → architecture → iterations → results → lessons).
2. **Depth over quantity**: few projects, well documented.
3. **Technical honesty**: failures and trade-offs are shown too.
4. **Everything deployed and verifiable**: every claim has evidence (demo, repo, metric).
5. **The portfolio is a product**: managed with a roadmap and recorded decisions, like any project.
